# Phase 5 — Arabic RTL frontend

Completed 2026-10-08. Phase 6 has not started.

Five Next.js pages now connect directly to the Phase 4 API: interpretation, source
search, digital library, engineering dashboard and methodology. The interface uses
Arabic RTL layout, local Arabic fonts, an emerald/warm-neutral palette, light/dark
modes, responsive navigation and reusable accessible components. It distinguishes
original quotations from generated synthesis and shows actual corpus readiness.

## Run and test

From the repository root, use separate terminals for the two servers:

```bash
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --no-access-log
npm --prefix frontend ci
npm --prefix frontend run dev
```

Open http://127.0.0.1:3000. See `docs/frontend.md` for configuration and production
serving. For checks, stop servers occupying ports 3000/8000 and run:

```bash
npm --prefix frontend run build
npm --prefix frontend run typecheck
npm --prefix frontend run format:check
npx --prefix frontend playwright install chromium
npm --prefix frontend run test:e2e
```

- Production build passed; all five pages and the not-found route prerendered.
- TypeScript check passed, including after final source formatting.
- Prettier check passed.
- Final browser suite: **8 tests passed in 21.2 seconds** against temporary local

  issues and a short-window sidebar overflow were fixed before the final run.

- After the final browser run, only source formatting, development metadata and
  documentation changed; type/format checks were rerun. The unchanged backend's
  full 52-test suite was not repeated in Phase 5.
- No live DeepSeek call, Firefox/WebKit check, manual screen-reader audit, fresh
  machine installation, load test or public deployment was performed.

## Remaining limitations

The reviewed corpus still contains only two AI-assisted Nabulsi passages. Ibn Shahin
awaits review, and Ibn Sirin awaits OCR. Interface polish does not increase corpus
coverage or establish live-model faithfulness. The chapter filter intentionally
matches a complete title, and Arabic morphology remains a retrieval limitation.
Generation requires explicit UI opt-in and an enabled/keyed backend; it can incur
provider charges and sends the entered query and selected excerpts to DeepSeek.

The application remains local and unauthenticated. Phase 6 will cover further tests
and packaging, including Docker, only after confirmation per the original plan.
